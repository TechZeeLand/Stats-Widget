# Other distributions

Installs no system packages; builds eww if missing and installs the widget.

Run from the repository root: `./distros/generic/install.sh` (or use the one-line installer, which picks this for you).
Options: `--autostart --start --widget-only --no-eww --no-deps`.

Install the packages listed in `distros/generic/install.sh` yourself first (see docs/INSTALL.md).
