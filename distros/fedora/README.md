# Fedora

Fedora Workstation, KDE and other spins, Nobara.

Run from the repository root: `./distros/fedora/install.sh` (or use the one-line installer, which picks this for you).
Options: `--autostart --start --widget-only --no-eww --no-deps`.

Packages (dnf): git gcc pkgconf-pkg-config curl fontconfig pciutils gtk3-devel gtk-layer-shell-devel pango-devel gdk-pixbuf2-devel cairo-devel glib2-devel libdbusmenu-gtk3-devel openssl-devel python3 python3-gobject python3-cairo gtk3 gtk-layer-shell
