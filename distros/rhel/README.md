# RHEL family

RHEL, AlmaLinux, Rocky Linux, CentOS Stream, Oracle Linux 9/10. Enables EPEL and CRB.

Run from the repository root: `./distros/rhel/install.sh` (or use the one-line installer, which picks this for you).
Options: `--autostart --start --widget-only --no-eww --no-deps`.
