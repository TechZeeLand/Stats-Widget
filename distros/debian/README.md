# Debian / Ubuntu family

Debian 12+, Ubuntu 22.04+, Linux Mint, Pop!_OS, elementary OS, Zorin, Kali.

Run from the repository root: `./distros/debian/install.sh` (or use the one-line installer, which picks this for you).
Options: `--autostart --start --widget-only --no-eww --no-deps`.

Package names verified against Ubuntu 24.04 (apt). Python 3.10 on Ubuntu 22.04 is fine (built-in TOML reader).
